# Lumen Docs · 清简文档

**Lumen Docs 1.0.0** 是以飞书文档阅读体验为参考的独立 Obsidian 主题，强调清晰层级、克制配色和舒适留白，非飞书官方产品。最低要求 Obsidian 1.5.0，无需 Flow Edit、Things 或其他插件。

## 功能

- **文档排版**：统一标题层级、段落与列表间距，去除标题装饰横线；默认正文宽度 800px、行高 1.7。
- **引用与高亮**：引用使用中性细竖线和正常字形；文字高亮提供适合浅色、深色背景的颜色。
- **标注块（Callout）**：淡底色、细边框、语义色图标，保留自定义标题和折叠行为；支持显式启用紧凑笔记块。
- **表格与代码**：弱化表格网格线，增加单元格留白，统一代码圆角。
- **浅色与深色**：覆盖原生编辑视图、阅读视图及侧栏、标签页等界面颜色。
- **可选调整**：可用 Style Settings 调整正文宽度和行高；字体与字号继续在 Obsidian 外观设置中选择。

主题只改变外观，不改写 Markdown，不注入运行脚本，也不联网。

## 快速开始

### 安装

1. 在笔记库中新建 `.obsidian/themes/Lumen Docs/`。
2. 将本仓库根目录的 **`theme.css` 和 `manifest.json`** 复制到这个文件夹；或解压发布包，将其中整个 `Lumen Docs` 文件夹放到 `.obsidian/themes/`。
3. 打开 Obsidian「设置 → 外观 → 主题」，选择 **Lumen Docs**。列表未刷新时，重新打开设置或重启 Obsidian。
4. 按自己的偏好选择浅色或深色模式；建议分别查看实时预览和阅读视图。

安装后的结构：

```text
你的笔记库/
└─ .obsidian/
   └─ themes/
      └─ Lumen Docs/
         ├─ manifest.json
         └─ theme.css
```

安装不需要 Node.js。升级时覆盖上述两个文件；切回其他主题即可撤销主题外观，笔记内容保持不变。

### 一分钟体验

在笔记中粘贴以下内容，切换实时预览与阅读视图查看：

```markdown
## 清晰的文档层级

正文保留自然的 **加粗** 与 *斜体*，重点可用 ==文字高亮==。

> 普通引用使用细竖线，不强制斜体。

> [!note|compact]
> 紧凑笔记块：图标与正文同行。

> [!warning]- 注意事项
> 有标题、可折叠的标注块保留原生操作。

| 项目 | 说明 |
| --- | --- |
| 留白 | 表格保持清晰易读 |
```

## 紧凑高亮块

使用原生 Callout 元数据明确选择紧凑形式：

```markdown
> [!note|compact]
> 这里是高亮内容。
```

紧凑样式仅作用于带 `compact` 元数据、不可折叠的 `note` 块，会收起可见标题，使图标与正文同行。需要可见标题时使用普通 `[!note] 标题`；带 `+` 或 `-` 折叠标记的块始终保留标题和折叠按钮。

主题不会猜测默认 Note 标签是否来自手写标题，也不会自动改写已有高亮块。

## 调整宽度与行高

可选安装 Style Settings，在其中的「Lumen Docs · 清简文档」调整正文宽度（560–1200px）和行高（1.4–2.2）。不安装也能正常使用默认样式。

也可以在笔记库 `.obsidian/snippets/lumen-custom.css` 中写入以下片段，再到「设置 → 外观 → CSS 代码片段」启用：

```css
body {
  --lumen-page-width: 880px;
  --lumen-line-height: 1.8;
}
```

字体与字号使用 Obsidian 自己的外观设置。其他主题片段或插件样式可能覆盖本主题设置。

## 与 Flow Edit 的分工

| 组件 | 职责 |
| --- | --- |
| Lumen Docs | 正文字体层级、间距、引用、高亮块、表格和界面颜色 |
| Flow Edit（可选） | 斜杠插入、块操作、浮动工具栏及用户主动设置的块颜色和对齐 |

主题不解析 Flow Edit 的颜色、对齐注释，也不提供编辑工具栏。停用 Flow Edit 后主题仍生效；切换主题后 Flow Edit 仍可使用。两者均不依赖 Things。

## 构建与验证

主题运行只需要两个安装文件。若要生成本地发布目录，可在仓库根目录用 Node.js 执行：

```sh
node build.cjs
```

安装文件、README 和许可会复制到 `release/Lumen Docs/`。`release/` 与 ZIP 为生成产物，不纳入 Git；无需安装 npm 依赖。

已在真实 Obsidian 1.14.4 中验证标题、引用、标注块、文字高亮、表格及与 Flow Edit 双向独立运行。手机端、其他插件组合尚未完整验收。

源码文件：`theme.css` 为完整主题，`manifest.json` 为主题信息，`build.cjs` 为发布脚本。
